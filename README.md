# TFG-Predicci-n-CSTR-con-PI-mediante-RRNN
Se presenta el código y el informe completo de mi TFG, en el que predigo el comportamiento de un RCTA (CSTR) usando redes neuronales. Es un trabajo de iniciación al Deep Learning y muy didáctico para cualquier usuario que pretenda aprender el uso de RRNN desde el inicio, mediante un ejemplo típico en el ámbito de la Ingeniería Química.
